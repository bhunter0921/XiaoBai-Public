# 角色设计（Confirmed）

仅维护比熊角色，采用半写实卡通精修。

## 比熊（xiaobai-bichon）

采用自然比熊犬形象，而非标准圆头美容造型。
- 面部偏尖、较修长；鼻口收窄，保留深褐色鼻头。
- 较小自然垂耳，不能做成大圆耳或西高地立耳。
- 头身比例适当卡通化但不夸张；暖白卷毛，深色眼睛。
- 四肢与爪子采用较纤细、自然的比例，腿部毛发不应显得过于蓬大；以已确认的 16 帧挠痒修订样品为比例基准。此约束适用于所有后续比熊动画，已确认的旧样品在生产加工时检查一致性。
- 日常：粉蓝色胸背带，自然四足宠物。
- 工作：眼镜、白衬衫、蓝领带；专注而非开心，轻微皱眉、身体前倾、双爪快速敲击键盘。工作样品 Working v0.2 已确认，作为风格基线而非已发布素材。
- 可适度使用汗滴、速度线、电脑、文件、耳麦；不同工作级别有明显差异。
- 睡眠：自然趴卧、闭眼、呼吸。保持尖脸、小耳与真实头身比例。
- 角色参考图和完整动画原稿尚待归档；不要把生成参考图的背景/文字作为运行资源。

## 美术验收要求

不同视角和动作维持统一角色特征；逐帧检查深浅背景，眼睛、鼻子及其他实体深色区域不得误抠除为透明；无粉紫色或棋盘格杂边；

思考形象补充：抬头时头顶仍须保持饱满蓬松的白色卷毛，不呈秃头观感；不以扩大耳朵或头骨比例代替毛量。托腮、视线上移与慢节奏为 A06 的主要动作，避免混入 A07 快速打字。

A05 v0.2 小耳朵修订已确认，后续睡眠与日常动作以该较小、贴近头部的自然垂耳为参考，避免耳部毛量过大使脸显圆。
