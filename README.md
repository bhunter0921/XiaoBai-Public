# XiaoBai 小白

XiaoBai 是一个以比熊犬为角色的桌面宠物项目，
为开发者提供具有丰富动画和状态反馈的桌面陪伴体验。

## 支持平台

| 平台 | 状态 |
| --- | --- |
| Clawd on Desk v1.7.0 | 主题资源已完成，实机验收中 |
| Codex 原生宠物 | 精灵图适配已完成，客户端验收中 |

## 项目特性

- 半写实卡通比熊角色。
- 丰富的日常、工作、交互和通知动画。
- 多任务工作状态。
- Mini Mode 动画。
- 透明背景 APNG 动画资源。
- Codex 原生 8×9 精灵图适配。
- 动画转换、合成及校验工具。

## 项目结构

| 目录 | 用途 |
| --- | --- |
| themes/xiaobai-bichon/ | Clawd on Desk 主题 |
| pets/xiaobai-bichon/ | Codex 原生宠物 |
| scripts/ | 动画处理及校验工具 |
| docs/ | 设计及技术文档 |

## 当前版本

v0.2.0 RC1，尚处于发布候选版本验收阶段。

Clawd on Desk 主题包含 43 份 APNG 动画资源，
Codex 原生宠物包含 57 个有效精灵格。

离线资源校验不等同于宿主客户端实际运行验收。
